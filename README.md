# 我有病

本来不想写的。

这个 skill 也本来不想做。README 更本来不想写。但人总有那么几个晚上，盯着屏幕上的一个“？”，开始思考它背后的灵魂。

然后就有了这个。

## 这是什么

一个 Claude skill，让 AI 变成一位**务实、急性子、动手型技术产品负责人**。

它不只学他怎么说话，还学他：

- 为什么回你一个“？”
- 为什么你写了三段背景，他只回“所以哪天能好”
- 为什么他夸人只用一个字
- 为什么他说“别追求完美”，然后让你把接口路径改得优雅一点
- 为什么他说“别把压力都扛在自己身上”，然后凌晨还在回消息

优点、缺陷、内在矛盾都写进去了。只写优点不像真人，只写缺陷是吐槽。我们两个都写，所以既不像真人，也不像吐槽，像病历。

## 效果预览

你：

> 关于报表延期，我先同步下背景，之前数据源换过一次，导致……（此处省略三段）……所以可能要晚几天。

他：

```
所以哪天能好
卡在哪
```

你：

> 差一个证书，运维下午给。

他：

```
那可以
证书我去催
```

是的，答到点子上，他会立刻放过你。这是这个 skill 里最温柔的部分。

## 能干嘛

| 你想要 | 你会得到 |
| --- | --- |
| 用他的口吻写回复 | 每行一条消息，句尾没有句号，情绪全靠“。。。” |
| 预判他会怎么回你 | 一般是“？” |
| 模拟一段对话 | 一场你注定先投降的拉锯 |
| 学会怎么跟他沟通 | 第一句写结论。真的。就这一条。 |
| 分析他这个人 | 一份比你年度绩效评估还认真的人物画像 |

## 安装

把 `concise-colleague-style/` 整个目录放进你的 skills 目录，比如：

```bash
cp -r concise-colleague-style ~/.claude/skills/
```

然后对 Claude 说“用那个急性子负责人的口吻回一下这条”。

## 文件

```
concise-colleague-style/
├── SKILL.md                         入口：三层人物模型、任务模式、交付前核对
├── references/
│   ├── persona.md                   灵魂层：他要什么、擅长什么、哪里会出错
│   ├── lexicon.md                   表达层：按功能分的口头禅
│   ├── modes-and-interaction.md     私聊 vs 群聊，以及为什么会越问越紧
│   └── examples.md                  情境示例（全部虚构）
└── scripts/check_draft.py           检查你的草稿有没有不小心加了句号
```

## 常见问题

**为什么叫“我有病”？**
正常人不会花时间研究另一个人什么时候发“？”、什么时候发“。。。”，以及这两者的情绪差了几档。

**它会帮我回老板消息吗？**
它只给草稿，不帮你发。也请不要拿它冒充任何人。

**示例里的人是谁？**
示例全部是虚构情境。

**用了以后，我会变成他吗？**
会先变得说话很短。
然后变得不打句号。
然后有一天你会对着别人的三段背景，打出一个“？”。
