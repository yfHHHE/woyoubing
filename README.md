## 2. 这是什么

一个 Claude skill，让 AI 扮演一位**务实、急性子、动手型的技术产品负责人**。这种人你身边大概也有一个：消息很短，不打句号，你写三段，他回一行。

它不只学他怎么说话，还学他在乎什么、擅长什么、会在哪里出错。只学说话方式，得到的是一个“说话很短的人”；把这三层都学了，才能回答我那天晚上的问题：

**那个“？”到底是什么意思。**

（答案在 2.1。）

### 2.1 效果预览

你：

> 关于报表延期，我先同步下背景，之前数据源换过一次，导致……（此处省略三段）……所以可能要晚几天。

他：

```
所以哪天能好
卡在哪
```

你：

> 差一个证书，运维下午给。

他：

```
那可以
证书我去催
```

所以那个“？”的意思是：先说结论。

我花了一晚上，得出了一句他用两个字就能说完的话。

### 2.2 能干嘛

| 你想要 | 你会得到 |
| --- | --- |
| 用他的口吻写回复 | 每行一条消息，句尾没有句号 |
| 预判他会怎么回 | 省下一晚上。这本来是我该吃的药 |
| 模拟一段对话 | 一次彩排，正式的那次少紧张一点 |
| 学会怎么跟他沟通 | 第一句写结论。就这一条，我学了很久 |
| 分析他这个人 | 一份人物画像，优点和缺点都写了，写得比我自己的年终总结还认真 |

## 3. 安装

把 `concise-colleague-style/` 整个目录放进你的 skills 目录，比如：

```bash
cp -r concise-colleague-style ~/.claude/skills/
```

然后对 Claude 说“用那个急性子负责人的口吻回一下这条”。

## 4. 文件

```
concise-colleague-style/
├── SKILL.md                         入口：三层人物模型、任务模式、交付前核对
├── references/
│   ├── persona.md                   他要什么、擅长什么、哪里会出错
│   ├── lexicon.md                   按功能分的口头禅
│   ├── modes-and-interaction.md     私聊和群聊的区别，以及为什么会越问越紧
│   └── examples.md                  情境示例（全部虚构）
└── scripts/check_draft.py           检查你的草稿有没有不小心加了句号
```
