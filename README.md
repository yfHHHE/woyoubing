# 我有病

本来不想写的。

这个 skill 也本来不想做。README 更本来不想写。但人总有那么几个晚上，盯着屏幕上的一个“？”，开始思考它背后的灵魂。

然后就有了这个。

## 这是什么

一个 Claude skill。你说一句“我有病”，Claude 就换一种方式跟你说话：**务实、急、直接、短**。

它不只是回得短，还会：

- 你写了三段背景，它回“所以哪天能好”
- 你绕了一圈，它回你一个“？”
- 你做出了能跑的东西，它回“牛”，然后问能不能用到真实场景
- 你想替别人的锅兜底，它说“别，那是他的事”
- 你答到点子上，事情马上就过去了

优点、毛病、内在矛盾都写进去了。只写优点是客服，只写毛病是发脾气。两个都写，所以既不像客服，也不像发脾气，像病历。

## 效果预览

你：

> 我有病。关于报表延期，我先同步下背景，之前数据源换过一次，导致……（此处省略三段）……所以可能要晚几天。

Claude：

```
所以哪天能好
卡在哪
```

你：

> 差一个证书，运维下午给。

Claude：

```
那可以
先把别的准备好
证书到了直接发
```

答到点子上，事情就过去了。

## 能干嘛

| 你说 | 你会得到 |
| --- | --- |
| 我有病，帮我看下这个报错 | 三行：原因、怎么改、改完看什么 |
| 我有病，给我写个脚本 | 完整代码，外面只包两句话 |
| 我有病，我这周做不完了 | 先问哪部分做不完，再帮你砍 |
| 我有病，你看我这个方案 | 一个“牛”或一个“？”，取决于方案 |
| 我好了 | 恢复正常 |

## 安装

把 `woyoubing/` 整个目录放进你的 skills 目录，比如：

```bash
cp -r woyoubing ~/.claude/skills/
```

启动方式只有一种：先说“我有病”。

不说“我有病”，它不会出来。说“我好了”，它就走。

## 常见问题

**为什么叫“我有病”？**
正常人不会花时间研究一个“？”和一个“。。。”差了几档。另外，这也是启动口令。

**它会凶我吗？**
会急，不会骂人。急的是事，不是你。

**说话变短，信息会少吗？**
不会。代码、文档照给，只是外面那层客套没了。

**用久了会被传染吗？**
会先变得说话很短。
然后变得不打句号。
然后有一天你会对着别人的三段背景，打出一个“？”。
